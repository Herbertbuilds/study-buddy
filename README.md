# Study Buddy

Study Buddy is a browser extension for turning on-page questions into study material. It scans page content, detects question blocks, and helps work through answers.

## Features

- Page scanning for questions
- Answer cards with confidence indicators
- Auto-scan support
- Provider quick-toggle
- Keyboard shortcut
- Dark mode

## Development

This is a Chromium browser extension using Manifest V3.
